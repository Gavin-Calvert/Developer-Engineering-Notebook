CSforGood - Sports Information Guide

The Sports Information Guide is an easy solution for anybody who's heard people talking about sports and wanted to be included but had absolutely no clue what they were talking about. Users can read about basic information about some sports, as well as common terminology that can be heard in casual conversation or color commentary.
For this project, we used html and css, as they're the best for simple website-making. To finish the work in time, we split it up, with me working on the writing and James working on the code. We spent the first couple days designing a basic layout, then the next few days gathering research and implementing a simple layout for the website, then the rest of the time writing for each sport and refining the code to adjust its appearance.
